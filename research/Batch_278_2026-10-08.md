## Newly read sources and original engineering content
1. **Japanese / C# OpenCvSharp distance transform:** https://qiita.com/tkhshiq/items/c65a4d5203c03dffe5df — Computes distance-to-boundary maps for a binary closed shape, contrasts L1/L2/chessboard distance and mask approximations. Conditions: binary, closed, single shape. DTF use: physical-space mask inset and local feature width diagnostics; assumptions do not hold for arbitrary soft-alpha art.
2. **Chinese / Zhang–Suen thinning implementation:** https://www.cnblogs.com/xiaxuexiaoab/p/15842240.html — Two-phase 8-neighbor thinning with transition count A(P)=1, neighbor count 2<=B(P)<=6 and direction-specific deletion predicates. Deletions are batched per sub-iteration. DTF use: optional topology/stroke analysis; skeleton is NOT printable artwork.
3. **Russian / signed-distance-field vector rendering experiment:** https://habr.com/ru/articles/318880/ — Contrasts triangulated geometry with SDF glyph/icon rendering, shader smoothstep and screen-space fwidth; warns about diagonal/corner artifacts and scale-dependent smoothing. DTF use: preview/geometry QA for binary icons, not a source-resolution substitute or universal alpha-matting model.
4. **Turkish / Chan–Vese region-based segmentation implementation:** https://medium.com/@BerkayAydeniz/segementasyon-ve-aktif-kontur-aras%C4%B1nda-bir-algoritma-chan-vese-c16f963950c1 — Level-set signed-distance mask, region mean energy, curvature regularization, Sussman reinitialization, convergence and max-iteration stop. Region-based segmentation can help where gradient edges are weak, but smoothness can destroy fine distressed art. Requires fail-safe topology review.
5. **Portuguese / original libpng ICC warning case:** https://pt.stackoverflow.com/questions/425770/capturar-python-libpng-warning — Shows actual iCCP 'known incorrect sRGB profile' and cHRM mismatch diagnostics escaping Python warnings filters because libpng emits them through a native layer. Do NOT follow suggestions to indiscriminately strip all color metadata: record and validate ICC/sRGB/gAMA/cHRM, quarantine or repair only under explicit policy.
6. **Japanese / CascadePSP coarse-mask refinement tutorial:** https://qiita.com/john-rocky/items/731ec70c27ba4b5faa07 — Refines a coarse segmentation mask using a separate segmentation-refinement model. Example writes JPEG, which cannot preserve print-master transparency. For DTF retain lossless soft-alpha outputs and source/provenance, and test foreground survival.
7. **Chinese / distance-transform raster skeleton algorithm:** https://www.cnblogs.com/zhongHW/p/11047015.html — GIS-derived distance-to-background and repeated raster thinning, including Manhattan/chessboard/Euclidean metrics and neighborhood classification. Independent method from Zhang–Suen; not necessarily topology-equivalent. Example's city-block distance expression needs unit/parentheses review before reuse.

## Engineering synthesis and acceptance tests
**Physical stroke survival**: lock final width/height and pixels-per-mm. For an opaque/binary working mask, compute Euclidean distance transform D and optional medial axis. Approximate local full stroke thickness near medial-axis points as 2*D*(mm_per_pixel), but mark branch points, acute corners, antialiasing, and anisotropic pixel aspect as uncertain. Record quantiles and minimum stable segment lengths, not only a single global minimum. Report local white-underbase risk if 2*choke >= measured local stroke width. Never silently erode features.

**Topology before/after**: compare 8-connected foreground component count, enclosed-hole count (consistent 4/8 connectivity convention), skeleton endpoints/junctions and signed-distance changes before/after cleaning, thresholding or choke. Distressed dots and punctuation may be intentional. Preserve soft alpha as a separate artifact; threshold only for explicitly declared QA masks.

**Algorithm routing**: distance-transform and Zhang–Suen are geometric diagnostics on binary masks, not background-removal substitutes. Chan–Vese is a fallback segmentation method for suitable region-contrast images; CascadePSP is a refinement stage, not a guarantee of true detail recovery. Save the original and output masks; guard memory/time and allow cancellation.

**SDF contract**: use signed-distance representations for scale-dependent previews of monochrome glyphs or for geometry analysis, not as proof that original raster DPI is sufficient. Re-rasterize vector masters at final physical size when vector provenance exists; do not claim raster-to-SDF recovers missing design detail.

**Color integrity**: capture native PNG/libpng diagnostics, validate embedded ICC and PNG color metadata, and preserve original bytes/hash. Do not 'fix' an iCCP warning by blindly deleting profiles; create a separately color-managed derivative only with explicit conversion and recorded source/destination profiles.

**RIP ownership**: if RIP/PrintMode owns white generation, choke, ICC or halftone, Smart Prepress only reports expected risks and hands off the original/approved master. Device-specific min-dot and adhesive-transfer calibration remains mandatory.
