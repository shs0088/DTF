## New materially distinct pages read

1533. https://habr.com/ru/articles/468067/ — Russian. Alpha compositing / coverage / premultiplication / filtering and interpolation. Read directly. Key finding: alpha combines opacity and pixel coverage; straight-alpha filtering/interpolation can leak hidden RGB and create colored halos, while premultiplied-alpha processing avoids that class of fringe. This strengthens AlphaConvention normalization before blur/resample/edge QA.

1534. https://python.armert.com.tr/50-goruntu-isleme/morfoloji/ — Turkish. Mathematical morphology tutorial. Read directly. Key finding: erosion/dilation/opening/closing intentionally remove protrusions/specks or close holes/gaps; structuring-element behavior changes topology. For DTF alpha/white masks these operations require final-physical-scale kernel selection plus component/hole/stroke survival checks.

1535. https://www.how-ar.com/how-to-use-digital-image-processing-techniques/ — Arabic. Digital image-processing tutorial. Read directly. Key finding: smoothing/noise reduction trades noise suppression against edge/detail preservation; prepress denoise must be routed by noise class and gated by protected-edge/detail residual rather than applied globally.

1536. https://learnopencv.com/image-resizing-with-opencv/ — English implementation tutorial, updated 2026. Read directly. Key finding: interpolation family must follow transformation intent; INTER_AREA is suited to shrink, cubic/linear use different neighborhoods, nearest preserves discrete samples, and arbitrary width/height changes can distort aspect ratio. DAPR must record geometry transform, kernel and aspect-ratio policy and re-QA at final size.

1537. https://learnopencv.com/image-matting-with-state-of-the-art-method-f-b-alpha-matting/ — English implementation tutorial. Read directly. Key finding: segmentation probabilities can seed a trimap, dilation creates the unknown band, and FBA jointly predicts foreground, background and alpha. Generated trimaps can be imprecise, so segmentation is not alpha authority; foreground RGB and alpha need separate reconstruction QA.

1538. https://dtfdatabase.com/blog/dtf-color-management/ — English DTF color-management/RIP guide. Read directly. Key finding: linearization/TVI, ICC conversion, GCR/UCR, white density and choke are separate controls. Choke solves registration exposure, whereas density/linearization solve different tone/ink-response problems; they must not be collapsed into one white-strength setting.

1539. https://dtfs.co/blog/how-to-create-underbase-for-dtf-printing.html — English DTF underbase workflow. Read directly. Key finding: underbase density, choke and edge feathering are distinct variables and should be validated by test output. File-side prepress should therefore export explicit white geometry/provenance while avoiding claims that image analysis alone can determine physical ink density.

## Engineering synthesis
1. Normalize AlphaConvention before any operation that mixes neighboring RGBA samples. For blur, resample, rotate and warp, process in a premultiplication-safe representation or equivalent mathematically correct route, then verify multi-background composites.
2. Split morphology into purpose-tagged operations (speck removal, hole closing, choke, spread). Every operation records structuring-element shape/size in physical units and is rejected if glyph topology, connected components, holes or minimum printable strokes are lost.
3. Denoising is a routed candidate stage, not a generic cleanup switch. Add RemovedDetailResidual and protected-edge masks so texture/glyph/halftone loss is visible and measurable.
4. Geometry provenance becomes mandatory: source dimensions/aspect, target physical size, scale factors, interpolation kernel, letterbox/crop policy and inverse transforms for masks. Any later resize invalidates halftone/choke physical calibration.
5. Matting routing remains segmentation -> trimap/unknown-band construction -> alpha/foreground estimation -> RGB decontamination -> multi-background QA. A segmentation mask is not print alpha authority.
6. White-prepress controls remain orthogonal: WhiteAuthority, white geometry/choke/spread, white density/tonal policy, RIP linearization/TVI and color separation/GCR/UCR. Image-side analysis may validate geometry and relative coverage but must not claim physical ink laydown without calibrated device/RIP evidence.
