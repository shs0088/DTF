## Engineering synthesis
1. Morphology must use explicit `MorphologyPurpose = SPECK_REMOVAL | HOLE_REPAIR | CHOKE | SPREAD | MASK_REPAIR` plus structuring-element shape and physical radius. Erosion/dilation are geometry-changing operations, so connected components, holes, glyph topology and minimum physical strokes must be checked after them.
2. Split segmentation/matting artifacts from composited/exported images. A model may legitimately return only an alpha map; compositing, foreground-RGB decontamination, white-underbase derivation and PNG export are separate stages with separate provenance.
3. Add provider/runtime lifecycle to model provenance. A retired API or changed model must not silently alter production behavior; persist provider, service/model version, runtime/backend and deprecation status where known.
4. Make multi-background composite QA standard for transparent assets: checkerboard plus black, white, neutral gray and garment-relevant colors. This catches residual white/dark/color contamination hidden by a single preview background.
5. Dithering/screening provenance must record `family + kernel/matrix + scan order + strength + working transfer domain + working resolution + pre-downsample factor + final physical scale`. A resize or resolution change after screening invalidates calibration.
6. Browser-local ONNX/WASM inference is a privacy/deployment property, not a quality guarantee. It still needs model/backend provenance, alpha occupancy/edge QA and explicit manual-edit history.
