## Engineering synthesis

### 1. Screening artifacts must be exported losslessly and validated after encoding
The French gottrix implementation converts to grayscale before Floyd–Steinberg diffusion, preserves dimensions, and explicitly warns that JPEG can soften the one-bit dot pattern while PNG preserves it sharply. Smart Prepress should therefore treat export encoding as part of screening provenance and prohibit lossy recompression of production screening masks. A post-encode binary/palette integrity check should verify that the intended dot topology survived export.

### 2. Ordered dithering needs matrix identity and color-step authority
InstantGradient exposes Bayer 2x2, 4x4 and 8x8 matrices plus dither size and color-step count. These are not interchangeable presentation controls: matrix period, quantization levels and effective pixel scale determine the spatial-frequency signature. Store `matrix_identity + matrix_period + color_steps + physical_scale` and regenerate after any geometry change.

### 3. Halftone/vector export can decouple screen geometry from raster resolution
Jukebox Print exposes Floyd–Steinberg, Atkinson and Bayer alongside cell size, dot size, contrast, midpoint, transparent paper and PNG/SVG/PDF export. For Smart Prepress this supports a vector-capable screening artifact when the selected screen family can be represented geometrically. Vector export can preserve dot geometry through layout scaling better than resampling a screened raster, but final RIP rasterization still needs minimum-dot/minimum-gap and physical-scale QA.

### 4. Morphology should be intent-routed after thresholding, not applied as generic cleanup
The Turkish Armert tutorial explicitly frames morphology as cleanup after thresholding: erosion removes thin protrusions/specks, dilation grows regions/closes small gaps, opening removes small foreground noise, and closing fills small holes/cracks. Smart Prepress should route morphology by defect class (`SPECK_REMOVAL`, `HOLE_REPAIR`, `GAP_BRIDGE`, `CHOKE`, `SPREAD`) and run topology/minimum-stroke checks instead of exposing a generic cleanup-strength slider.

### 5. Threshold selection must record prefiltering because denoise can change the selected boundary
The Traditional-Chinese OpenCV tutorial compares global, adaptive-mean, adaptive-Gaussian and Otsu thresholding, and demonstrates Otsu after Gaussian prefiltering on noisy input. Adaptive thresholding uses neighborhood size and constant C; Otsu chooses a global threshold by minimizing weighted within-class variance. Therefore `ThresholdArtifact` provenance must include prefilter identity/parameters, threshold family, block size, C and selected threshold. Prefiltering is not a harmless implementation detail because it can move the segmentation boundary.

### 6. Unsharp masking is frequency-selective and kernel-dependent, not merely an amount slider
Niigata University's Japanese tutorial derives unsharp masking as original minus blurred image, multiplied by an enhancement coefficient, then added back to the original. It explicitly notes that the blur/convolution function determines which frequency band is emphasized. Smart Prepress should store the blur kernel/scale and gain separately, and QA sharpening for halo/ringing, noise amplification, alpha-edge displacement and minimum-feature distortion. Sharpening remains distinct from deconvolution/restoration.
