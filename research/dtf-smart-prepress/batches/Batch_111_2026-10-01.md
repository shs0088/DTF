## New materially distinct pages read

1549. https://webai.show/models/modnet-portrait-matting/ — English browser implementation of trimap-free portrait matting. Read directly. MODNet emits continuous soft alpha rather than a hard mask, separates semantic/detail/fusion branches, supports dynamic aspect ratio, and demonstrates WebGPU fp32 with WASM q8 fallback plus Web Worker execution. Engineering transfer: route soft-edge subjects to matting, record inference backend/precision, preserve original geometry when resizing matte output, and compare partial-alpha occupancy across backends because quantization can alter edge values.

1550. https://vayce.app/tools/image-denoiser/ — English edge-aware mathematical denoiser. Read directly. Separates reduction amount, scale, edge protection and chroma-noise control; stores scale relative to the shorter image side rather than a fixed pixel radius and explicitly says denoising cannot reconstruct motion/focus/JPEG-lost detail. Engineering transfer: parameterize denoise scale relative to geometry/physical output, separate luminance/chroma cleanup, and require weak-texture/detail QA because edge protection cannot distinguish all texture from noise.

1551. https://pngtoolskit.org/denoise-png — English browser median-filter implementation. Read directly. Explains radius versus blend strength, chroma-only filtering, salt-and-pepper suitability, ordering relative to resizing/sharpening, and explicitly passes alpha unchanged. Engineering transfer: route impulse noise to median filtering, keep RGB cleanup alpha-preserving by default, denoise before upscaling/downscaling when appropriate, and postpone sharpening until residual noise is controlled.

1552. https://snapcorn.com/resources/alpha-channels-and-matting — English alpha/matting explainer. Read directly. Distinguishes binary masks from continuous mattes, explains straight/premultiplied convention mismatch as a dark-edge cause, and notes that matting must estimate both opacity and foreground color. Engineering transfer: diagnose alpha convention before blaming segmentation; preserve a transparent master and keep foreground-RGB estimation/decontamination separate from alpha geometry.

1553. https://tools.quickyla.com/quickfix/image-noise-reducer/ — English browser edge-aware denoising implementation. Read directly. Uses similarity-weighted neighborhood smoothing rather than uniform blur and exposes adjustable denoise strength. Engineering transfer: retain a non-generative edge-aware baseline for deterministic comparison against learned denoisers; acceptance still requires glyph/texture/alpha-edge residual QA.

## Engineering synthesis
1. Add MattingBackend provenance: model, precision/backend, input transform, output transform. fp32 WebGPU versus q8 WASM may change fractional-alpha edge populations; backend fallback must not be invisible to QA.
2. Add PartialAlphaOccupancyDelta as a regression signal across segmentation/matting/export backends. Soft-edge content should not silently collapse toward binary alpha after quantized inference or format conversion.
3. Denoise parameters should be geometry-aware, not arbitrary fixed pixels. Store neighborhood/noise scale relative to source/final geometry and invalidate it after later resampling.
4. Keep NoiseClass routing explicit: median for impulse/salt-and-pepper, edge-aware smoothing for continuous sensor/chroma noise, learned reconstruction only when justified. Denoise is not deblur or super-resolution.
5. Preserve alpha by default during RGB denoising. Alpha modification requires a dedicated alpha-refinement stage with separate edge/topology QA.
6. Order cleanup intentionally: remove noise before enlargement that would magnify it; avoid sharpening before denoise because sharpening amplifies residual noise; re-run physical printability checks after any geometry-changing transform.
7. Diagnose dark/light fringes in layers: AlphaConvention -> alpha geometry -> foreground RGB contamination -> underbase geometry -> registration. A convention mismatch can mimic a bad cutout.
