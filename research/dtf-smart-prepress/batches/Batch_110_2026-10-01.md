## New materially distinct pages read

1545. https://ja.pixfix.com/ — Japanese image-restoration implementation page. Read directly. Distinguishes a graphics mode built around a color-median filter plus iterative detail restoration from a photo mode extending anisotropic diffusion; the photo path introduces a JPEG distortion score based on cross-8x8-block versus within-block neighbor distances and increases diffusion across block boundaries when blocking is strong. Engineering transfer: classify degradation before denoising; JPEG-block cleanup, impulse-noise cleanup and photographic sensor-noise cleanup should not share one generic smoothing operator. Add block-boundary artifact diagnostics and removed-detail QA.

1546. https://mergeimages.net/denoise-image — English browser-side denoising implementation page. Read directly. Uses box-blur neighborhood averaging with strength mapped to increasing square windows and explicitly acknowledges the sharpness/smoothing trade-off; PNG export is used when transparency must be retained. Engineering transfer: box blur is a low-complexity baseline only, useful for comparison/fallback, but should be rejected around glyphs, alpha boundaries, distressed texture and halftone dots unless structural QA passes.

1547. https://www.artedge.ai/ai-denoise-image/ — English AI denoising workflow page. Read directly. Separates luminance noise, chroma noise and compression artifacts; exposes asynchronous/background processing, multiple enhancement levels, fixed high-resolution output behavior and batch processing. Engineering transfer: NoiseClass must be explicit; learned denoising/upscaling is a reconstructive transform, not neutral cleanup, so it requires topology/text/edge/color/alpha regression gates and immutable job settings for asynchronous batches.

1548. https://imagehub.ai/ai-denoise/ — English AI denoising workflow page. Read directly. Explicitly separates noise from blur and low resolution, distinguishes luminance from color noise, limits concurrency per tool tab, and recommends full-size review because fine texture can overlap noise. Engineering transfer: route Denoise, Deblur and Upscale as distinct defect classes; do not let one enhancement model silently solve all three. Add texture-risk classification and full-resolution candidate QA before accepting denoising.

## Engineering synthesis
1. Add DegradationClass before denoising: SENSOR_NOISE, CHROMA_NOISE, IMPULSE_NOISE, JPEG_BLOCKING, SCAN_ARTIFACT, UNKNOWN. Operator eligibility follows the defect model instead of a universal denoise slider.
2. Add JPEGBlockScore/BlockBoundaryResidual. JPEG damage has 8x8 spatial structure; a block-aware cleanup path can target it without applying equal smoothing everywhere.
3. Keep box blur only as a transparent baseline/fallback. Its predictable averaging is useful for regression comparison, but its edge/detail destruction makes it unsuitable as the production default for DTF artwork.
4. Separate Denoise, Deblur and Upscale routing. Noise, motion/focus blur and insufficient sampling are different defects; applying the wrong transform can fabricate detail or amplify artifacts.
5. Learned denoisers are reconstructive. Require RemovedDetailResidual plus glyph/topology, alpha-boundary, texture, color and minimum-feature survival checks at final physical size.
6. For async/batch processing, freeze per-job settings and record model/version/output geometry. A model that silently outputs 4K changes effective DPI and physical calibration, invalidating prior choke/halftone assumptions unless geometry is revalidated.
