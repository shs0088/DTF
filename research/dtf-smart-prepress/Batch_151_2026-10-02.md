## Engineering synthesis
- Minimum printable feature must be evaluated after white-underbase contraction at actual physical print size. Thin strokes/dots can disappear even when source raster resolution is nominally adequate.
- Store choke and minimum dot/gap in physical units (mm) as authority; pixel values are derived from final geometry/output resolution.
- Halftone geometry is physical: changing print size after screening changes dot dimensions. Therefore screen artifacts must be generated/validated at final print size.
- Keep artwork effective PPI, output DPI, LPI and minimum physical dot size as separate quantities.
- Fractional-alpha fades/shadows need a different route from solid artwork: selective halftoning can preserve solid shapes while replacing problematic low-alpha continuous regions with printable dots.
- Garment-color knockout must preserve hues the garment cannot supply; simple luminance/black deletion is insufficient for colored garments.
- White-underbase survival QA should run after final halftoning because choke can erase the smallest highlight dots.
- Browser-local processing is useful for privacy, but decoded-pixel/memory limits remain necessary; large print dimensions at high DPI can exhaust client memory.
