## Engineering synthesis
- Background-removal models are domain-specific. A portrait-focused matting model can preserve soft hair edges yet perform worse on products/logos. Smart Prepress should route extraction by content class and retain model provenance rather than treating all AI removers as interchangeable.
- Some browser pipelines compute a matte at model working resolution and upscale it back to source dimensions. Therefore matching output dimensions do not prove preservation of edge detail. Add matte-working-resolution/effective-edge-resolution provenance and QA for thin structures.
- Client-side inference is practical: RMBG/MODNet-style processing can run locally, improving privacy and reducing upload exposure. For production, model licensing must be tracked separately from technical quality.
- Dithering algorithms are not interchangeable. Floyd–Steinberg, Atkinson, Sierra, JJN, Bayer and blue-noise produce materially different spatial spectra. DTF screening selection should be evaluated by physical dot survival, isolated components, open-area ratio and white-support survival, not aesthetic preview alone.
- Perceptual palette matching in LAB can be useful before quantization, but generic palette dithering is not a substitute for RIP CMYK+W separation/screening.
- Heavy browser image processing can be moved to Web Workers so UI responsiveness is separated from deterministic pixel processing; this is useful for local preflight previews and batch QA.
