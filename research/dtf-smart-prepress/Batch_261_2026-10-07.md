## Engineering synthesis delta
### 1. Separate edge geometry from white-ink transfer function
A choke/decrease operation changes white-mask geometry. It cannot by itself solve semi-transparent gradient edges. The production model should represent:
- alpha/coverage geometry;
- neutral white-eligibility mask;
- RIP white transfer function / tonal white policy;
- global white density;
- physical choke/spread.
These must remain independent parameters.

### 2. Add transparency-aware white-risk simulation
For low-alpha edge pixels, simulate both color coverage and RIP-generated white. Flag cases where the RIP white response would make a visually translucent edge turn opaque or pale.

### 3. Garment-color separation should be perceptual, not "delete black"
For colored garments, use garment-color distance/tolerance plus a controlled transition band. Screen only the transition region where appropriate. Preserve differently hued dark colors even when their luminance is low.

### 4. Bind screening to physical output
A screening profile must bind target physical size + output DPI + LPI + angle + dot shape + calibrated minimum transferable dot. Any post-screen resize invalidates the screening and requires regeneration from the continuous-tone master.

### 5. Do not hard-code vendor thresholds as standards
Values exposed by web tools (minimum dot, cut points, tolerances, choke) are workflow examples, not universal DTF standards. Store them as calibration/profile parameters tied to printer, ink, film, powder, RIP/PrintMode and garment class.
