## Individually opened/read and accepted pages
1. **Japanese — FFmpeg fringe regression**: https://qiita.com/Phroneris/items/c82faca5ff1934c8e0ef — test overlays on opaque and transparent destinations; `unpremultiply` alone does not universally eliminate fringes and combining it with a premultiplied overlay option can reintroduce halos.
2. **Japanese — OpenCV alpha compositing**: https://qiita.com/smatsumt/items/923aefb052f217f2f3c5 — `IMREAD_UNCHANGED` returns BGRA; alpha compositing needs matching ROI slices when the overlay extends outside the background bounds.
3. **Japanese — high-resolution background matting**: https://qiita.com/koshian2/items/e08d1c0866b305288d2f — coarse model predicts alpha, foreground residual and error map; refiner works on selected uncertain patches at higher resolution. The method uses a background reference plate and is not a universal one-image cutout solution.
4. **Russian — JJN dithering C# implementation**: https://habr.com/ru/articles/863236/ — Jarvis–Judice–Ninke diffusion plus sRGB transfer handling; **code audit warning**: its `to_linear_space` low-end branch divides by **12.02**, while the standard sRGB divisor is **12.92**. Do not copy as authoritative without a known-answer test.
5. **English — alpha/gamma correctness**: https://lomont.org/posts/2023/correctalphagammaforimages/ — perform interpolation/compositing in linear light, use associated-alpha intermediates, and keep alpha linear. The correct sRGB decoding breakpoint and low-end divisor are 0.04045 and 12.92.
6. **Korean/English — text-guided segmentation + matting workflow**: https://huggingface.co/spaces/fantos/textcutobject/blob/main/README.md — Grounding DINO box proposals, segmentation, foreground-color estimation and matting, then RGBA export. README also declares automatic downsize above 2048px: record model input size and forbid treating resized masks as full-resolution evidence.
7. **Chinese — configurable rembg node**: https://comfy.icu/node/ZH_BackgroundRemover — model/resolution/blur/mask-offset/trimap thresholds/morphology exposed independently; sample defaults include inference resolution 1024 and alpha-matting OFF. A UI having settings does not establish validated DTF defaults.
8. **English — comparative error-diffusion tutorial**: https://beltoforion.de/en/dithering/index.php — quantization error distribution and directional artifacts; compare 1-D propagation with 2-D Floyd–Steinberg. The tutorial is a graphics algorithm reference, not evidence of physical DTF dot survival.
9. **Portuguese — locally hosted background-removal API implementation**: https://github.com/bbruno110/Remover-de-Fundo — README and distinct implementation files `app/image_utils.py`, `app/remover.py`, `app/api.py` were read. Code classifies backgrounds by border luminance/chroma, uses specialized art vs object routing, runs rembg/gradient matting, reuses model session and serializes inference. Alpha cutoff sets low-alpha pixels to zero; it can erase intended glow/soft fade and must be optional/QA-gated. ZIP/decoded-pixel and batch-size limits are useful patterns, not a completed security audit.

## Engineering synthesis / regression priorities
- **A-285**: Assert each RGBA buffer's association state and transfer function; perform resampling in linear premultiplied float, export correct straight-alpha PNG if required. Compare black/white/colored shirt composites; include alpha 0,1,128,255.
- **M-285**: Route matte processing by available evidence: source+clean background plate permits background matting; single arbitrary image needs segmentation/trimap/manual QA. Only refine uncertain patches and preserve disconnected dots/holes.
- **E-285**: Test old-background RGB contamination separately from alpha geometry; FFmpeg-style unpremultiply and color-decontamination are not interchangeable operations.
- **D-285**: Build known-answer sRGB tests at 0.04045 and 0.0031308, explicitly reject 12.02 vs 12.92 typo; record diffusion kernel/scan direction and compare tonal error with finite-border behavior.
- **P-285**: DTF preflight measures final-size feature widths in mm; do not prescribe RIP white choke, underbase, LPI or physical dot limits from screen simulations. Require printer/film/ink/transfer calibration.
- **U-285**: Keep decoded-pixel, upload-size, ZIP inflation, model memory and concurrency bounds; protect master and generate separate mockup derivatives. The Portuguese code's alpha cutoff is not safe as a universal automatic rule.
