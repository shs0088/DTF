## Engineering synthesis
### 1. Screen-space preview and print-space halftone QA must be separated
CLIP STUDIO documents that apparent moire can be zoom-dependent, but real moire can arise from overlapping screens with mismatched frequency or angle. It also warns that resizing/export processing can create moire. Smart Prepress should therefore distinguish preview aliasing from output-screen interference and store screen frequency, angle, raster geometry, scaling history, and output condition.

### 2. Never treat post-screen resize as harmless
Halftone geometry is physical output geometry. If a screened image is resized with a generic interpolation path, dot shape, spacing and periodicity change. The pipeline should prefer final geometry before screening; otherwise invalidate prior dot-survivability and moire QA and rerun them.

### 3. Alpha-aware resampling needs premultiplication discipline
Pillow's current Image.resize implementation converts LA/RGBA to premultiplied La/RGBa before non-nearest resampling and converts back afterward. This is strong implementation evidence for an alpha-safe resize stage. Resampling straight RGB values under fractional alpha can blend hidden background/edge colors and create fringes. Smart Prepress should explicitly track alpha representation and use premultiplied-alpha filtering or an equivalent mathematically correct method.

### 4. Upscaling cannot restore absent source information
Rasterbator explicitly distinguishes visual cleanup from recovery of missing detail. Upscale factor, sharpening and denoise should remain separate provenance fields, and acceptance must depend on effective source information plus feature-survival QA, not final pixel dimensions or embedded DPI alone.

### 5. Resampling method should be selected by transformation intent
Adobe's current Photoshop documentation distinguishes methods for enlargement, reduction, smooth gradients and hard-edged/pixel graphics. Smart Prepress should route by content class and direction of scale rather than one universal interpolation kernel.
