## Engineering synthesis additions
1. **White eligibility must be modeled separately from visible color.** DTF RIPs commonly derive the white plate from non-transparent artwork/alpha, then choke it inward. A low-alpha ghost pixel can therefore become a physical white/adhesive event even when visually negligible on screen. QA should render an explicit white-plate preview and report low-alpha components that still qualify for white.
2. **Choke must be specified in physical units and applied after final output size is known.** The Spanish DTF workflow explicitly converts requested choke against effective print size rather than trusting PNG DPI metadata. Smart Prepress should persist choke_mm plus derived pixels at final dimensions; metadata DPI alone is insufficient.
3. **Use topology-aware background removal for hard artwork.** Edge-connected flood fill can remove an exterior solid background while preserving legitimate same-colored enclosed regions. This is safer for logos/text than global color-key deletion. Enclosed counters/holes remain a separate QA class.
4. **Edge cleanup is a compound operation, not one threshold.** DTF edge defects include very-low-alpha ghosts, legitimate antialiasing, and foreground RGB contaminated by the removed background. Treat alpha cleanup, RGB decontamination and anti-alias reconstruction as separate bounded boundary-band operations with independent evidence.
5. **Route segmentation vs matting by boundary class.** Korean sources reinforce that hard masks are suitable for simple/solid boundaries, while hair, fur, smoke, glass and other mixed pixels require fractional-alpha matting. Trimap/unknown-band refinement remains the correct fallback when coarse segmentation is insufficient.
6. **Morphological choke needs feature-survival protection.** A circular structuring element is preferable when isotropic contraction is intended, but any erosion can erase narrow strokes/islands. Before accepting choke, compute minimum local feature width in millimetres and flag regions whose white support would collapse.
7. **Keep vendor numbers as calibration priors only.** Published choke ranges and assumed 300-DPI workflows are useful test starting points, not universal DTF standards. OutputCondition/RIPProfile must own calibrated limits for the actual printer, ink, film, powder and garment.
