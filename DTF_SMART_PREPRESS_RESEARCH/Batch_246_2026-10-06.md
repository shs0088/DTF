## Engineering synthesis additions
1. **Alpha thresholding is destructive topology conversion.** A threshold maps every semi-transparent pixel to either 0 or 1 coverage. It must therefore be an explicit production operation, never a generic cleanup step. Continuous-alpha subjects (hair, smoke, glass, feathered edges) should remain continuous unless a calibrated RIP requirement demands binary coverage.
2. **Separate alpha geometry from RGB contamination.** Adobe documents fringe as partially selected/anti-aliased edge pixels retaining the old background color. DTF QA must therefore inspect both alpha coverage and edge RGB contamination; a mathematically valid alpha can still generate a colored/white halo on a new garment or underbase preview.
3. **Edge refinement should be local and evidence-driven.** Enhance-edge style cleanup targets residual background color at the mask boundary. This supports a narrow boundary-band decontamination stage rather than global recoloring of the foreground.
4. **Underbase/choke values remain calibration parameters.** Re-read DTF-specific RIP sources reinforce that white density, choke and screening depend on printer, ink, film, powder, resolution and garment. Vendor values are test starting points, not universal DTF standards.
5. **Background-removal success is not print-readiness.** Consumer removal tools demonstrate segmentation convenience but do not establish DTF-safe edge color, alpha topology, white-plate behavior, minimum feature size or printability. Smart Prepress must keep removal and production acceptance as separate gates.

## Pipeline impact
Decode/validate -> normalize metadata/color -> establish final physical size -> optional content-aware denoise -> segmentation/matting -> boundary-band RGB decontamination -> topology-aware morphology/choke-spread -> final-resolution sharpening -> alpha/white-underbase composite QA -> ICC/RIP handoff. Binary alpha thresholding is disabled by default and exposed only as an explicit calibrated production transform.
