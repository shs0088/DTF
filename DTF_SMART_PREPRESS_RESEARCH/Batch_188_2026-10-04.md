## Accepted pages

### 1. WebpForge — Remove Background
Canonical URL: https://webpforge.com/remove-background
Language: English
Focus: deterministic solid-background removal, color-distance thresholding, edge feathering, local/browser processing.

Engineering notes:
- Uses Euclidean color-vector comparison rather than semantic segmentation for simple solid backgrounds.
- Adjustable tolerance is a distinct control from gradient edge feathering.
- This supports a cheap deterministic route before AI matting for studio-white/solid backgrounds.
- Edge feathering must not be treated as equivalent to foreground-color decontamination; it only changes transition opacity unless RGB is separately corrected.

### 2. Remove Bg Picture — Make Background Transparent
Canonical URL: https://remove-bg-picture.com/make-background-transparent
Language: English
Focus: local inference, alpha-capable output, batch/browser execution.

Engineering notes:

### 3. RemoveBGX — Background Remover
Canonical URL: https://removebgx.com/en
Language: English
Focus: segmentation followed by optional alpha matting.

Engineering notes:
- Explicitly separates coarse semantic segmentation from a second alpha-matting pass for hair, fur, tulle, glass, smoke, and other fractional-coverage boundaries.
- Alpha matting is unnecessary overhead for many hard-edged product shots.
- This reinforces a content-aware router: simple deterministic color removal -> opaque semantic segmentation -> alpha matting only where fractional coverage is plausible.
- Threshold tuning belongs after classification of edge type; hard thresholding can destroy legitimate partial transparency.

## Synthesis update

### Background-removal routing
Recommended routing hierarchy:
1. Already-valid alpha -> audit only.
2. Solid/studio background with separable color distribution -> deterministic color-distance/tolerance removal.
3. Complex but mostly opaque subject -> semantic segmentation.
4. Hair/fur/translucent material/smoke/glass or uncertain mixed pixels -> alpha matting.
5. After every route -> alpha topology audit + RGB edge-contamination audit + multi-background preview.

### Security/architecture implication
A browser-local prepress path can reduce upload exposure and latency for deterministic cleanup and compact models, but it still requires strict file-signature validation, decoded-dimension limits, memory budgeting, worker isolation, timeout/cancellation, and export validation.
