## Engineering synthesis additions
1. **Denoising must be edge-aware by content class.** Gaussian smoothing reduces noise but also softens boundaries. Median filtering is useful for impulse-like noise. Bilateral filtering adds an intensity-similarity term and can preserve edges better. Prepress should select denoising by detected noise/content instead of one global blur.
2. **Sharpen only after final resampling.** GIMP explicitly recommends sharpening at final resolution. Store radius in physical-output terms where possible, and run halo/color-fringe QA after sharpening. Threshold can protect smooth tonal regions from unnecessary sharpening.
3. **Do not dither alpha by default.** GIMP exposes dithering independently for alpha as well as RGB. For DTF, stochastic/ordered alpha quantization can alter coverage and therefore the derived white plate. Alpha dithering should be an explicit production mode, never an incidental side effect of palette reduction.
4. **Dither choice is a printability decision.** Floyd-Steinberg, Bayer, blue-noise and random families have different spatial structures. Selection should be validated against minimum transferable dot/feature size and the white-underbase interaction, not visual appearance on a monitor alone.
5. **ICC provenance remains multi-stage.** Assignment, conversion, soft-proof profile, rendering intent and black-point compensation are separate state. The pipeline should preserve them separately and detect accidental double conversion.
6. **Palette/index conversion is lossy prepress behavior.** Reducing available colors can create banding; dithering can mask banding but creates spatial texture. Ready-to-Print masters should remain continuous-tone unless an explicit RIP/halftone stage requires quantization.

## Pipeline impact
Recommended order remains: decode/validate -> normalize color metadata -> establish final physical size/resample -> content-aware denoise if needed -> segmentation/matting -> edge decontamination -> controlled morphology/choke-spread -> final-resolution sharpening -> alpha/white-plate QA -> color conversion/RIP handoff. Quantization/dithering should occur only in an explicitly modeled downstream production stage.
