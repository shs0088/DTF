## Sources read

1. https://pymatting.github.io/
   - Topic: trimap-based alpha matting and foreground estimation.
   - Key finding: alpha alone is not sufficient to obtain a clean cutout. PyMatting explicitly notes that simply multiplying the input RGB by the estimated alpha produces halo artifacts; foreground-colour estimation is a separate required stage.
   - Engineering consequence: keep alpha estimation, foreground RGB reconstruction/decontamination, and compositing QA as separate pipeline stages.

2. https://deltaecoreflowrip.com/
   - Language: Spanish.
   - Topic: production DTF RIP, white channel, halftoning, colour management.
   - Key finding: production RIP behavior combines 16-bit internal colour processing, ICC v2/v4, adjustable white boost/floor/choke, transparent-area cleanup, halftoning, and device-native PRN output.
   - Engineering consequence: artwork validity and output-device calibration must remain separate. Store white-generation parameters, screening mode, ICC/profile revision and printer/output target in a calibration profile rather than treating them as universal DTF constants.

3. https://photomop.com/glossary/image-matting
   - Topic: continuous alpha matting.
   - Key finding: matting estimates both continuous opacity and foreground colour under the compositing model I = alpha F + (1-alpha) B; this is fundamentally different from binary segmentation.
   - Engineering consequence: preserve continuous alpha for hair, smoke, glass, veils, motion blur and intentional soft edges; do not threshold by default.

4. https://yuustudio.app/ja/tools/background-remover
   - Language: Japanese.
   - Topic: browser-local RMBG background removal and edge refinement.
   - Key finding: the workflow separates model inference from edge smoothing/feather/sharpness and manual erase/restore, while previewing on transparent/white/black/custom backgrounds.
   - Engineering consequence: model output must not be accepted as final solely because the mask exists. Add post-inference edge QA and multi-background composite checks, and record inference backend separately from output dimensions.

## Synthesis delta

- Add explicit pipeline stages: segmentation/trimap -> continuous alpha estimation -> foreground RGB estimation/decontamination -> edge refinement -> multi-background composite QA.
- Add a rule that alpha quality and RGB edge cleanliness are independent pass/fail dimensions.
- Preserve continuous alpha by default; threshold only for a downstream requirement and record the threshold/provenance.
- Separate source artwork preflight from RIP/output calibration. Device profile should carry ICC revision, white boost/floor/choke, screening/halftone mode, output resolution/pass mode and target printer/electronics.
- For local/browser inference, record model family, backend (WebGPU/WASM/etc.), model input dimensions, matte dimensions, final canvas dimensions and any manual corrections.
